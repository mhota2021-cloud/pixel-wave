# Pixel Wave

名画のドット絵が、同心円の波で次々に入れ替わる作品です。
WindowsとmacOSではデスクトップの壁紙とスクリーンセーバーとして、
Linuxでは全画面表示として楽しめます。使う絵は8枚の名画から
選べ、自分の画像を足すこともできます。

## ダウンロードと入れ方

このリポジトリのReleasesページから、お使いのOSのファイルを
ダウンロードしてください。お金のかかる署名は使っていないため、
初回はOSの警告が出ます。越え方は各OSの所に書いてあります。

### Windows

- 置いてあるファイル：`PixelWave.exe`（と、スクリーンセーバー用の
  `PixelWave.scr`。中身は同じです）
- 入れ方：`PixelWave.exe` を好きな場所に置いて開きます。
  インストールは不要です。スクリーンセーバーは、アプリを
  起動して「スクリーンセーバーにする」を押すと登録されます。
- 警告の越え方：SmartScreenの警告が出たら「詳細情報」を押し、
  「実行」を押します（署名なしで配っているためです）。

### macOS

- 置いてあるファイル：`.dmg`（アプリとスクリーンセーバー入り、
  Apple SiliconとIntelの両対応）
- 入れ方：DMGを開き、「Pixel Wave.app」をアプリケーションフォルダへ
  写します。スクリーンセーバーは、アプリを起動して
  「スクリーンセーバーにする」を押すと置かれます。
- 警告の越え方：初回の起動でGatekeeperに止められたら、
  「システム設定」→「プライバシーとセキュリティ」で
  「このまま開く」を押します（macOS 15以降。公証を受けていない
  ための警告です）。

### Linux

- 置いてあるファイル：`.AppImage` と `.deb`（Ubuntu 24.04向け）
- 入れ方：`.deb` はダブルクリックか `sudo apt install ./ファイル名`
  で入れます。`.AppImage` は実行権限を付けてから実行します
  （`chmod +x ファイル名`、またはファイルのプロパティで
  「プログラムとして実行を許可」）。
- Linuxでは壁紙とスクリーンセーバーは無く、設定画面の
  「全画面で表示」で表示します。キー入力かクリックで終わります。

## 出典

絵の素材はパブリックドメインの名画で、Wikimedia Commonsから
取得しました。アプリの設定画面の下端にある「出典」からも
同じ一覧が見られます。

- 冨嶽三十六景 神奈川沖浪裏（葛飾北斎、1830～1832年頃）
- 星月夜（フィンセント・ファン・ゴッホ、1889年）
- 印象・日の出（クロード・モネ、1872年）
- 接吻（グスタフ・クリムト、1907～1908年）
- ラス・メニーナス（ディエゴ・ベラスケス、1656年）
- ヴィーナスの誕生（サンドロ・ボッティチェリ、1484～1486年頃）
- 叫び（エドヴァルド・ムンク、1893年）
- 真珠の耳飾りの少女（ヨハネス・フェルメール、1665年頃）

詳しい出典のURLは `app/assets/paintings/credits.json` にあります。

## 開発者向け

- `engine/`：描画エンジン（TypeScript、Canvas 2D）。
  使い方は `engine/README.md`。
- `app/`：Tauri 2のアプリ本体。開発とビルドの方法、
  壁紙とスクリーンセーバーの仕組みは `app/README.md`。
- 配布はGitHub Actionsで、`v1.0.0` のようなタグを押すと
  3つのOSのファイルがReleasesに置かれます
  （`.github/workflows/release.yml`）。プルリクエストでは
  テストが3つのOSで走ります（`.github/workflows/ci.yml`）。
